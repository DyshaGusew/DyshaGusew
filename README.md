## Проекты

> Часть проектов выполнена по коммерческим договорам (NDA), поэтому код закрыт — ниже описание задач и демо-версии.

### Система учёта грузоперевозок
Django + Django Admin. Учёт рейсов, грузов, документооборот.
Реализована **мультитенантность** — автоматическое создание изолированных инстансов (контейнеров) под каждого клиента с индивидуальным поддоменом.
Интеграция с **Контур.ЭДО** для электронного документооборота по грузоперевозкам.
Демо: _скоро_

### Система бронирования авиабилетов
Django (backend) + React (frontend). Поиск и бронирование рейсов, работа с городами/направлениями, личный кабинет.
Демо: _скоро_

### 🏁 Платформа для дрифт-соревнований
Next.js (frontend + backend раздельно) + Prisma + MariaDB. Регистрация участников, начисление очков по сезонам, OAuth-авторизация (Яндекс ID), загрузка медиа.
Полный цикл: от разработки до деплоя и поддержки на VPS (Nginx, PM2, CI-процесс через git pull + миграции).
Демо: _скоро_

### Приложение для ТСД (Android)
Приложение для сканирования грузов и штрихкодов при погрузке на рейсы, используется на терминалах сбора данных (ТСД) на складе.
